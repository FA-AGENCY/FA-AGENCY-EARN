# FA AGENCY™ EARN — Task Logo Assets

Place official social/platform logo files in this directory:

- `telegram.png` — Telegram logo
- `facebook.png` — Facebook logo
- `youtube.png` — YouTube logo
- `whatsapp.png` — WhatsApp logo
- `instagram.png` — Instagram logo
- `tiktok.png` — TikTok logo
- `twitter.png` — Twitter/X logo
- `website.png` — Generic website icon

**Recommended format:** PNG with transparent background, 64×64px or 128×128px.

These are used in the TasksScreen to display platform icons next to task cards.
The code references them via the task's `icon` field, mapped to `/src/assets/task-logos/{icon}.png`.

⚠️ Only use official brand assets with proper permission. The code will show an emoji fallback if files are missing.
