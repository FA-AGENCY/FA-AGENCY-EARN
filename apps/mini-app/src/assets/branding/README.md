# FA AGENCY™ EARN — Branding Assets

Place official branding files in this directory:

- `fa-agency-earn-logo.png` — Primary logo with text (horizontal)
- `fa-agency-earn-logo-square.png` — Square icon logo (for favicon, app icon)
- `fa-agency-earn-banner.png` — Full-width desktop banner (1200×400px recommended)
- `fa-agency-earn-banner-mobile.png` — Mobile banner (800×300px recommended)

These files are referenced in the Mini App code as:
  `/src/assets/branding/fa-agency-earn-logo.png`

The code will gracefully fall back to text-based logo if files are not present.
