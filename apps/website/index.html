নিরাপত্তা

আপনার অ্যাকাউন্ট সুরক্ষিত

🔐

HMAC-SHA256 Authentication

Telegram initData-এর cryptographic validation। কোনো password ছাড়াই সম্পূর্ণ নিরাপদ লগইন।

⚡

JWT Token Security

256-bit random secret, ৭ দিনের expiry। Server-side validation প্রতিটি request-এ।

🔒

Immutable Financial Ledger

ACID-compliant MongoDB transactions। লেনদেন একবার রেকর্ড হলে পরিবর্তন বা মুছে ফেলা সম্ভব নয়।

🛡️

Fraud Detection System

Real-time fraud event tracking। Suspicious activity শনাক্ত হলে account restrict করা হয়।

🚦

Rate Limiting

সমস্ত endpoint-এ rate limiting। Automation, scripting ও brute force সম্পূর্ণ blocked।

🔑

Idempotency Protection

Duplicate reward ও withdrawal prevention। একই transaction দুইবার process হওয়া সম্ভব নয়।

FAQ

সাধারণ প্রশ্নাবলী

FA AGENCY™ EARN কি সম্পূর্ণ বিনামূল্যে? ▼
হ্যাঁ, FA AGENCY™ EARN-এ যোগ দিতে কোনো টাকা লাগে না। শুধু Telegram account দরকার।
Withdrawal কতদিনে পাব? ▼
Withdrawal manually processed হয়। Processing time ভিন্ন হতে পারে। Admin approval-এর পর সরাসরি আপনার mobile banking-এ পাঠানো হবে।
Task pending থাকলে কী করব? ▼
Admin team সব task submission review করে। সময় লাগতে পারে। Support-এ যোগাযোগ করতে পারেন।
Referral bonus কখন পাব? ▼
আপনার referred বন্ধু যখন qualification criteria পূরণ করবে (active account, fraud-free), তখন server automatically reward credit করবে।
Account বন্ধ হলে কী হবে? ▼
নিয়ম ভঙ্গের কারণে account restricted বা suspended হতে পারে। এক্ষেত্রে support-এ appeal করা যাবে।
কোন দেশ থেকে ব্যবহার করা যাবে? ▼
বাংলাদেশ থেকে Telegram account দিয়ে ব্যবহার করা যাবে। Withdrawal বর্তমানে bKash, Nagad ও Rocket-এর মাধ্যমে বাংলাদেশে সীমাবদ্ধ।
