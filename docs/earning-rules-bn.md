# আয়ের নিয়ম

- রিওয়ার্ড কেবল server-validated এবং eligible activity-এর জন্য বিবেচিত হয়।
- reward amount, wallet balance এবং user identity frontend নির্ধারণ করতে পারে না।
- ad session-এর lifecycle, cooldown, daily limit এবং fraud checks প্রযোজ্য।
- Monetag বা অন্য provider-এর availability রিওয়ার্ড নিশ্চিত করে না।
- কোনো নির্দিষ্ট টাকা, CPM বা দৈনিক আয়ের নিশ্চয়তা নেই।
- duplicate completion, অস্বাভাবিক timing, automation এবং repeated abuse review-তে যেতে পারে।
- basic earning-এর জন্য বাধ্যতামূলক deposit নেই, যদি আলাদা করে প্রকাশ না করা হয়।
