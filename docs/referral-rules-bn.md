# রেফারেল নিয়ম

শুধু প্রকৃত ব্যবহারকারী এবং বৈধ referral activity গণনা করা হয়। নিজের জন্য একাধিক অ্যাকাউন্ট, self-referral, automation বা কৃত্রিম activity নিষিদ্ধ।

Referral reward server-side qualification, fraud checks এবং প্রকাশিত campaign rules-এর উপর নির্ভর করে। কোনো নির্দিষ্ট referral income নিশ্চিত নয়।

অস্বাভাবিক referral pattern পাওয়া গেলে event তৈরি করে review করা হতে পারে; legitimate balance স্বয়ংক্রিয়ভাবে মুছে ফেলা হয় না।
