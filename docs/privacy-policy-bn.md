# গোপনীয়তা নীতি

FA AGENCY™ EARN Telegram Mini App ব্যবহারের সময় প্রয়োজনীয় অ্যাকাউন্ট, Telegram পরিচয়, ব্যবহার, নিরাপত্তা এবং লেনদেন-সংক্রান্ত তথ্য সংরক্ষণ করতে পারে।

আমরা Telegram authentication data যাচাই করে ব্যবহারকারীর অ্যাকাউন্ট তৈরি করি। ওয়ালেট, লেজার, উত্তোলন, FraudEvent এবং AuditLog নিরাপত্তা ও হিসাবের জন্য সংরক্ষিত থাকে।

ব্যবহারকারীর তথ্য বিক্রি করা হয় না। নিরাপত্তা, আইনগত প্রয়োজন, প্রতারণা তদন্ত এবং পেমেন্ট যাচাইয়ের মতো বৈধ কারণে সীমিত তথ্য ব্যবহার করা হতে পারে।

কোনো গোপন token, password, database credential বা private API key frontend-এ পাঠানো হয় না।

অ্যাকাউন্ট বা ডেটা-সংক্রান্ত অনুরোধের জন্য Support চ্যানেলে যোগাযোগ করুন।
